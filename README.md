Task: 
•	Analyze a given CSV dataset.
•	Perform basic data exploration and preprocessing.
•	Create and present 3 meaningful visualizations with insights.

Dataset Used: Titanic.csv Dataset

What I Did:
Today I worked on the Titanic dataset. First, I loaded the dataset into Python using Pandas and checked the rows, columns, and data types.
Then I checked for missing values in the dataset. I found some missing values in the Age and Embarked columns.

Data Cleaning:
•	Filled missing values in the Age column using the median value.
•	Filled missing values in the Embarked column using the most frequent value (mode).
•	Removed duplicate records from the dataset.

Visualizations Created:
1.	Survival Distribution
This chart shows how many passengers survived and how many did not survive.
Observation: More passengers died than survived.
2.	Gender Distribution
This chart shows the number of male and female passengers.
Observation: Male passengers were more than female passengers.
3.	Passenger Class Distribution
This chart shows the number of passengers in each class.
Observation: Most passengers traveled in Third Class.
